# Security and safety reports

This repository controls physical hobby machinery. Treat unexpected movement,
magnet overheating, failure to stop, exposed credentials, and unsafe defaults as
high-priority reports.

Use GitHub private vulnerability reporting when it is enabled. Otherwise open a
minimal issue without secrets, camera URLs, private video, Bluetooth addresses,
or personal paths and ask a maintainer for a private contact method.

For an active hardware problem, disconnect physical power first. Do not continue
testing solely to collect logs. The software's Bluetooth halt is not a substitute
for power isolation.

Support bundles are sanitized automatically, but reporters should still inspect
every ZIP before uploading it publicly.
